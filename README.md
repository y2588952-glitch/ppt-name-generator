# PPT 台卡批量生成工具

一个运行在 **Windows 本地浏览器** 中的网页工具：上传已有的 PowerPoint（.pptx）模板 → 导入姓名名单 → 设置重复次数与排列顺序 → 自动把姓名按模板格式填入对应的文本框 → 生成可用 WPS / Microsoft PowerPoint 打开的新 PPTX 文件。

**全程本地处理，不上传任何数据到云端，不执行上传文件中的宏。**

---

## 一、功能特性

- 上传并分析 `.pptx` 模板：显示文件名、幻灯片数量、页面尺寸、每个文本框的位置 / 尺寸 / 字体 / 字号 / 对齐方式。
- 选择作为台卡标准模板的页面，并**手动勾选**需要替换的姓名文本框（系统只提供「疑似姓名框」预选提示，绝不擅自替换）。
- 姓名导入：网页粘贴、上传 TXT（自动识别 UTF-8 / GBK 编码）、上传 XLSX / XLSM（可选择工作表和姓名所在列）。
- 生成规则：每个姓名重复次数、填写顺序（从上到下 / 从左到右）、每页姓名个数、保留末页空白台卡、生成范围、去除首尾空格。
- **折叠式台卡**：支持「同一姓名填入所有选中文本框」，用于对折后正反两面显示同一姓名的台卡。
- 保留模板格式：页面尺寸、背景、Logo、图片、边框、线条、形状、颜色、字体、字号、对齐、位置与大小尽量保持不变；仅替换用户指定的姓名文本框。
- 生成新文件（不覆盖原文件），自动分页，生成后可下载。
- 生成前计算并预览「生成姓名总数、幻灯片页数」。

## 二、环境要求

- Windows 10 / 11
- Python 3.9 及以上（推荐 3.10+）
- 本机无需联网即可运行

已在 **Python 3.14 + Flask 3.1 + python-pptx 1.0.2 + openpyxl 3.1** 环境下验证通过。

---

## 三、安装步骤

1. 确认已安装 Python（在命令提示符中运行 `python --version` 能看到版本号）。
2. 进入项目目录：

   ```bat
   cd C:\Users\联想\Desktop\ppt-name-generator
   ```

3. （推荐）创建并激活虚拟环境：

   ```bat
   python -m venv .venv
   .venv\Scripts\activate
   ```

4. 安装依赖：

   ```bat
   python -m pip install -r requirements.txt
   ```

   > 如果只想快速运行，也可直接 `pip install Flask python-pptx openpyxl`。

---

## 四、启动本地网页

在项目目录下运行：

```bat
python app.py
```

看到如下提示即启动成功：

```
Running on http://127.0.0.1:5000
```

打开浏览器访问 **http://127.0.0.1:5000** 即可使用。

> 工具只在 `127.0.0.1`（本机）监听，外部设备无法访问，也不会把数据发送到互联网。

## 五、使用方法（六步）

1. **上传模板**：点击或拖拽 `.pptx` 文件到上传区。解析后选择「作为台卡标准模板的页面」。
2. **选择姓名框**：勾选需要填入姓名的文本框。系统会预选疑似姓名框，**请人工确认**。
3. **导入姓名**：粘贴 / 上传 TXT / 上传 Excel（Excel 需选择工作表和姓名所在列）。
4. **设置规则**：重复次数、填写顺序、每页姓名个数、是否折叠式台卡等。
5. **预览**：查看姓名总数与预计页数。
6. **生成并下载**：点击「生成 PPT」，完成后下载新文件。

默认输出文件名：`原文件名_台卡生成结果_日期时间.pptx`，原文件不会被修改。

## 六、用你自己的模板测试

项目已附带对真实模板 `10.23台卡（大1）.pptx` 的验证。建议按下面步骤用你自己的模板试一次：

1. 启动工具后，在第一步上传你的 `.pptx` 模板。
2. 在「选择模板页面」中，选**带示例姓名的那一页**（通常姓名会被自动预选为「疑似姓名框」）。
3. 在第二步确认勾选的正是「姓名」文本框；Logo、固定文字、装饰边框等**不要勾选**。
4. 若你的台卡是「一页对折、正反显示同一姓名」，请勾选第四步的 **折叠式台卡** 选项。
5. 粘贴几个测试姓名，设置重复次数，生成后打开下载的文件，用 WPS / PowerPoint 检查姓名位置、字体、Logo、边框是否正常。

## 七、已测试通过的功能

- 模板结构分析（文本框数量、位置、尺寸、字体、字号、对齐）。
- 重复次数、填写顺序（t2b / l2r）、每页姓名个数、姓名范围、去除空格。
- 空白姓名框的填入。
- 末页未使用位置「保留空白」与「保留原文字」两种模式。
- 折叠式台卡（同一姓名填入多个文本框）。
- 多页生成与自动分页，输出文件可被重新读取、姓名数量 / 页数 / 图片 / 页面尺寸核对一致。
- 空名单、未选姓名框、无效页码等异常提示。
- 端到端 API 流程：上传 → 分析 → 导入 → 生成 → 下载。

> 已用真实模板 `10.23台卡（大1）.pptx`（26MB，含图片 Logo、折叠式台卡）验证：姓名正确填入、Logo 图片完整保留、页面尺寸不变。

## 八、已知限制

- **SmartArt、图表、OLE 对象、媒体、复杂组合图形**：python-pptx 会整体复制，但无法保证其内容可编辑或绝对无损；上传后会给出风险提示，请生成后用 WPS / PowerPoint 打开核对。
- **表格内的文字**：暂不支持替换，按原样复制。
- **字体**：依赖本机已安装的字体；若模板使用了本机没有的字体，生成后显示可能回退到默认字体。
- **超长姓名**：填入后若超出文本框，工具不会自动缩小字号（避免破坏格式），请自行调整姓名长度或模板。
- 特殊动画 / 过渡 / 母版级复杂结构：尽量复制，但不保证绝对无损。
- XLSM 宏：只读取数据、**不执行宏**；原文件不被修改。

├── static/
│   ├── style.css           # 网页样式

python -m pytest tests/ -v

## 十、安全与隐私说明

- 所有文件只在本地处理，不上传任何服务器。
- 不执行上传文件中的宏 / 脚本。
- 上传文件与生成结果保存在 `temp/` 目录，会在启动时及新任务时自动清理 24 小时前的临时文件。
- `.gitignore` 已排除 `temp/`、`*.pptx`、`*.xlsx`、`*.xlsm` 等，**请勿手动把含个人姓名的文件提交到 GitHub**。
